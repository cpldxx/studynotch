How it works

It is one app. No server, no account.

Structure

The path of one question

Finding the page

The first time it sees a PDF, it extracts the text of every page and keeps it (next to a copied PDF in materials/<kind>/_text/, and for a PDF in a linked folder in ~/StudyNotch/.cache/text/, so the linked folder is never written to). It removes all spaces and punctuation from both the selected sentence and each page’s text and lowercases them, then looks for the page that contains the beginning, middle and end of the sentence. Words broken by line breaks or hyphens still match.

Files with no text layer, such as scanned PDFs, can’t be searched. Ask with a capture instead and it reads the picture itself.

How the right-click button appears

macOS doesn’t let an app add items to another app’s right-click menu; the only allowed route is inside Services at the bottom. So instead of putting the button in the menu, it attaches the button right above it.

  1. It notices that a right-click happened. It looks only at where you clicked, not at what you clicked.
  2. It carries on only if the front app has selected text. For apps that don’t say, it judges by whether you just dragged.
  3. It reads the position and size of the menu window that just opened and shows the button above it at the same width. It never reads the window’s contents.
  4. When the menu closes, the button disappears.

How selected text is read

  1. Nothing is read before you press the button.
  2. When you press it, it asks the front app for its current selection, using the Accessibility permission.
  3. In apps that don’t answer, it copies once and immediately restores your clipboard.

Judging drift

During a session it checks the frontmost app every 2 seconds, and for a browser, the address of the tab.

  1. Allowed if you pressed “It’s for study” for it in this session.
  2. Allowed if it is on that course’s allow list or the shared allow list.
  3. A distraction if it is on the distraction list.
  4. Otherwise it isn’t counted.

In the lists, an entry with a dot is a site: youtube.com matches m.youtube.com but not notyoutube.com. An entry without a dot is an app name.
